# 📧 AI Mail Assistant for Gmail

## Overview

The **AI Mail Assistant for Gmail** is a powerful Chrome Extension designed to boost your email productivity directly within the Gmail interface. Leverage advanced Artificial Intelligence to instantly **correct grammar** and generate context-appropriate **email drafts** or **replies**—all using your own secure API key.

## ✨ Features

* **Grammar & Spelling Correction:** Instantly proofread and fix mistakes in your email drafts with a single click.
* **AI Email Generation:** Provide a short prompt (e.g., "Ask for a status update on project X") and let the AI generate a full, professional email draft.
* **Template Storage:** Save your most frequently used email formats or messages as reusable templates directly in the extension.
* **Secure API Key Usage:** The extension uses your private API key for all AI interactions, ensuring you have full control over usage and costs.
